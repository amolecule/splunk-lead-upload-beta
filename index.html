Turn one attendee worksheet into a reviewable Marketo Non-Partner upload CSV.

Step 1

Choose the attendee file and worksheet

Choose the row containing the column names.

One active child campaign per file.

Privacy: the workbook is read and converted in this browser tab. The app does not upload or save it. It loads the spreadsheet-reading library from jsDelivr; workbook rows are not sent to that library host.

Beta uses the Non-Partner template schema snapshot (observed 2026-10-01). It does not connect to Salesforce or refresh SharePoint picklists; confirm campaign activity, child status, type, status, and current template values before use.

Step 2

Check the field matches

We matched familiar column names where possible. Confirm the mapping before exporting. Leave a field unmatched if your source does not contain it.

Attendance is not consent. Select 1 or 0 only when the source documents it.

Step 3

Review the conversion

This creates a UTF-8 CSV only. Review the file and confirm campaign activity/child status in Salesforce before sending it to Workfront.
